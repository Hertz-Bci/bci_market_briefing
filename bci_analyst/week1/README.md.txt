# day1: 美敦力研发投入趋势除探

## 项目目标 
用Python读取美敦力近5年财务数据，画出研发投入趋势图，并尝试商业解读。

## 技术线
- Python 3.9
- Pandas(数据读取)
- Matplotlib (可视化)

## 关键发现
- 成功读取并解析了CSV格式的财务数据。
- 2019-2023年间，美敦力投入研发的趋势是：2019-2023年呈波动状态，2019-2022年连续上升，2023年出现下降。
- 作为一家医疗科技巨头，科技公司的研发投入上升。因为研发是未来增长的动力，虽然短期会增加成本，但能形成技术壁垒，是维持其技术护城河的关键。
